# Nyktra

> A modern, terminal-based chat application built with Python.

**Nyktra** is a keyboard-focused **TUI (Terminal User Interface)** chat application designed for people who prefer the speed, simplicity, and control of the terminal.

Built with Python and designed around an interactive terminal experience, Nyktra aims to provide a clean and efficient way to communicate without relying on a traditional graphical interface.

---

## ✨ Features

> 🚧 Nyktra is currently under active development.

- 🖥️ **Terminal User Interface** — A full interactive chat experience inside your terminal.
- ⌨️ **Keyboard-first** — Navigate and interact without constantly reaching for your mouse.
- ⚡ **Fast & Lightweight** — Designed to keep the client simple and responsive.
- 🔌 **Real-time Communication** — Built with real-time messaging in mind.
- 🐍 **Python-powered** — Developed using Python and its modern ecosystem.
- 🎨 **Rich Terminal UI** — Clean terminal rendering and interactive components.
- 📖 **Source Available** — The source code is publicly available for study, modification, and non-commercial use.

## 🚀 Getting Started

### Requirements

Before running Nyktra, make sure you have:

- Python **3.11+**
- Git
- A terminal that supports modern terminal features

### Clone the repository

```bash
git clone https://github.com/t3chn0-17/Nyktra.git
cd Nyktra
```

### Create a virtual environment

```bash
python -m venv .venv
```

Activate it on Windows:

```powershell
.venv\Scripts\Activate.ps1
```

Or on Linux/macOS:

```bash
source .venv/bin/activate
```

### Install dependencies

```bash
pip install -r requirements.txt
```

### Run Nyktra

```bash
python -m nyktra
```

> The installation and launch commands may change during development.

## ⌨️ Keyboard-First Philosophy

Nyktra is designed around the idea that **the terminal can be a complete user interface**.

Instead of navigating through windows and menus with a mouse, Nyktra aims to make common actions accessible through intuitive keyboard controls.

This makes the application particularly suitable for users who enjoy:

- Keyboard-driven workflows
- Terminal applications
- TUI environments
- Minimal interfaces
- Developer-oriented tools
